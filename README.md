# 每周三练 · 增肌打卡（PWA）

个人健身训练打卡应用，纯静态网页，可安装到安卓手机桌面的 PWA。

**在线访问**：https://kaige-mr.github.io/workout-tracker/

## 训练计划（固定）

- 周一：胸部 + 三头肌 —— 坐姿器械推胸 4×8–12、上斜哑铃卧推 4×8–12、绳索三头肌下压 3×10–15
- 周三：背部 + 二头肌 —— 高位下拉 4×8–12、坐姿划船 4×8–12、哑铃弯举 3×10–15
- 周五：腿部 + 肩部 —— 坐姿腿举 4×10–12、罗马尼亚硬拉 4×8–12、器械肩推 3×8–12
- 周二、周四、周六、周日休息

## 安卓安装到桌面

1. 用 Chrome 打开 https://kaige-mr.github.io/workout-tracker/
2. 点右上角菜单（⋮）→「安装应用」/「添加到主屏幕」
3. 桌面会出现「训练打卡」图标，点开即全屏运行，断网也能打开

## 数据说明（重要）

- 打卡记录保存在**手机本机的浏览器 localStorage** 中（键名 `simple_gym_checkins_v1`），**不是 GitHub 云同步**，不需要注册登录。
- 关闭应用、重启手机都不会丢；部署新版本也不会清除记录。
- 更换手机、卸载 Chrome 或清除浏览数据会丢失记录，请定期在页面里用「导出打卡备份」保存 JSON 文件，换机后用「导入备份」恢复。
- 如果你之前用过单文件版 HTML 并有打卡记录：先在旧页面导出备份 JSON，再在新 PWA 里导入即可迁移（两者备份格式相同：`gym-checkins-v1`）。
